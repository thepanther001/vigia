# Identidad visual de Vigía

<img src="../assets/logo/vigia-logo-color.png" alt="Vigía" width="280">

**Concepto:** un vigía en su torre — atento, tranquilo y que avisa a tiempo.
El símbolo es una **V en forma de escudo** (protección) con un **punto naranja de alerta** encima (el vigía que avisa).

## Archivos del logo (`assets/logo/`)

| Archivo | Uso |
|---|---|
| `vigia-logo-color.svg` / `.png` | Uso principal sobre fondos claros |
| `vigia-logo-blanco.svg` / `.png` | Sobre fondos oscuros |
| `vigia-logo-negro.svg` | Impresión en una sola tinta |
| `vigia-icono-*.svg` | Solo el símbolo (avatar, íconos) |
| `vigia-favicon-*.png` | Ícono de navegador (16, 32, 48, 180 y 512 px) |
| `../social-preview.png` | Imagen para compartir el repo (1280 × 640) |

Los SVG tienen el texto convertido a trazados: no necesitan fuentes instaladas.

## Colores

| Color | Hex | Uso |
|---|---|---|
| Azul Vigía | `#2A78D6` | Color principal, enlaces, NVD |
| Azul marino | `#1B2B48` | Texto del logo y títulos sobre fondo claro |
| Naranja alerta | `#EB6834` | Acento: alertas, CISA KEV. No usar para texto pequeño sobre blanco |

## Tipografías

| Fuente | Dónde se usa | Pesos |
|---|---|---|
| **Montserrat** | Título principal del panel y piezas promocionales | 700 |
| **Inter** | Toda la interfaz del panel, tablas y el Excel | 400 · 500 · 600 · 700 |
| **JetBrains Mono** | Identificadores CVE, fórmulas, URLs y código | 400 · 500 |

- Las cifras de tablas usan **números tabulares** de Inter para que se alineen.
- En el Excel se usa Inter; si la PC no la tiene instalada, Excel usa su fuente por defecto.
- Las tres son gratuitas: [Montserrat](https://fonts.google.com/specimen/Montserrat) · [Inter](https://rsms.me/inter/) · [JetBrains Mono](https://www.jetbrains.com/lp/mono/).

## Reglas rápidas

- No deformar, rotar ni cambiar los colores del logo.
- Dejar alrededor del logo un espacio libre de al menos la altura del punto naranja.
- Tamaño mínimo del logo completo: 96 px de ancho (en pantalla).
- Mayúsculas solo para siglas y etiquetas cortas (CVE, KEV, CRÍTICA).
